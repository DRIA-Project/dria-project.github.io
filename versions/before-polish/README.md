# DRIA — version before the overall polish

This is a self-contained backup of the page immediately before the overall visual and functional update. `index.html`, CSS, and JavaScript are preserved exactly from the saved pre-update files. The original thirteen videos, poster frames, and four paper figures/PDFs referenced by that HTML are included.

Open `index.html` directly, or visit `/versions/before-polish/` when serving the repository root. The polished page remains at `/`.

BibTeX remains hidden and Code remains TBD, matching that version. External font/icon CDNs are referenced as before. No files are shared with the current page, so later changes to the current page do not change this backup.

`SHA256SUMS` records the backed-up files. From this directory, run `sha256sum -c SHA256SUMS` to check integrity.
